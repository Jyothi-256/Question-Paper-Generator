# Question-Paper-Generator

Description:

Developed a web-based application that automates the generation of question papers for universities and colleges. The system uses AI/NLP techniques to create balanced sets of questions based on difficulty levels, unit distribution, and mark allocation. Built with Python (Django framework), the project integrates a database of questions categorized by subject, unit, and marks, and dynamically compiles them into formatted papers.

Key Features:

Automated question selection based on unit, marks (2, 5, 10), and difficulty level.

Admin panel for faculty to add, edit, and categorize questions.

Randomization algorithm ensures unique papers for each generation.

Export papers in PDF/Word format with proper formatting.

Secure login and role-based access for faculty and coordinators.

Tech Stack:

Backend: Python, Django

Frontend: HTML, CSS, JavaScript

Database: SQLite/MySQL

AI/NLP: Question classification and randomization logic

Impact:

Reduced manual effort in preparing exam papers.

Ensured fair distribution of questions across units and marks.

Improved efficiency for faculty and placement coordinators.
